- 复合回复的父消息包含别的事项，直接全文导入会污染 Spec。来源展示的 target 也必须核对当前事项。

- 本次工具发现没有会话级 clear 能力。终端 clear、JS 内核 reset 或新建任务都不等价；不得声称已清空/已完成清空后恢复。
