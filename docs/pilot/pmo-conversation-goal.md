## 原生目标正文

把当前钉钉研发助手交付为个人和内部团队可稳定使用的“自然协作入口 + 可验证研发交付引擎”，优先解决需求误解、测试遗漏、回复生硬和主 Agent 上下文过载。产品、测试、项目经理和研发人员只需在已授权钉钉群内用自然语言提出、补充、更正和跟进事项，不需要任务编号、技术命令、固定模板或文档。

Meta 根据多轮对话区分新需求、同一事项补充、查询、解释、致谢及控制意图，保留已确认事实和消息来源；归属不清时用业务名称问清，仅追问 1–3 个会改变结果的关键问题，回答后不反复追问。角色和定向提醒须有真实依据。回复先回答当前问题，通常 1–3 句，清楚说明改了什么、实际效果、验证情况或下一步；不把“已记录/已规划/候选就绪”说成“修改完成”，普通修改不要求“接受结果”。
