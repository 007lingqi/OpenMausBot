## Pitfalls Encountered

- 浏览器有两个相同 analytics URL 的标签页，其中一个仍为一个月范围。必须核实目标页实际日期，不能只按 URL 认定当前状态。用量页是 https://chatgpt.com/codex/cloud/settings/analytics#usage 。
- CUA 通过 `cua.getState()` 重新发现浏览器和邮件标签页。不要依赖上个上下文的变量、标签编号或 AX 元素编号。Gmail 可按主题关键词“Codex Pro”、额度“90%”“5%”定位已有支持线程，再核实正文。
- 原生 Chrome 获取应用时，bundle ID 因磁盘上有重复应用而产生歧义；`cua.getApp('/Applications/Google Chrome.app')` 曾成功。
- 用户会切换前台标签、浏览器 profile，并曾取消操控。出现用户改变页面提示后必须刷新状态；不要把文字粘进其他网站。浏览器控制曾遇到 CDP 和审批超时，超时不代表动作成功或明确拒绝；重新读取结果后再决定是否重试。
- 正文一次粘贴超时后实际未执行，随后重建变量并粘贴成功。附件操作中断后用户已上传全部六个附件，最后已核验，不要盲目重复上传。
- 截图工具输出实际为 JPEG，最初 PNG 扩展名已按文件签名改为 JPG，没有修改图片字节。
- 助手没有点击过 Send；操作中断不能解释为已经发送。不得宣称问题解决。
- 当前工具目录未提供会话 clear 操作。CUA reset、归档或新建任务均不等同于 `/clear`。本次只能保存并提交交接，再由用户执行 `/clear` 和重载提示；没有执行过清理或清理后重载。
